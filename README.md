# Virtual Business Solutions by Janice — Portfolio

Updated GitHub Pages portfolio for Janice Lomocso.

## Publishing
Upload the contents of this folder to the root of the `janice-portfolio` GitHub repository and publish from the `main` branch / root folder in GitHub Pages.

## Contact form
The inquiry form uses FormSubmit and sends submissions to `hellojanicecrm@gmail.com`.

**Important:** FormSubmit normally sends a one-time activation/confirmation email the first time the form is submitted from the published site. Open that message in `hellojanicecrm@gmail.com` and confirm it. After activation, future form submissions should be delivered to that inbox.
