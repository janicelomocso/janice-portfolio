# Virtual Business Solutions by Janice — Portfolio

Static portfolio website ready for GitHub Pages.

## Before publishing
1. Open `index.html` and replace `YOUR_EMAIL_HERE` with your preferred business email.
2. Preview `index.html` in a browser.
3. Upload the contents of this folder to a GitHub repository.
4. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.

All images used by the site are in `/assets`.
